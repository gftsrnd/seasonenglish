# Bản sửa code 4300 và bản người dùng 4175

| Bản | Địa chỉ | Docker project | Dùng cho |
| --- | --- | --- | --- |
| Người dùng | http://127.0.0.1:4175, công khai qua https://e4s.gfts.vn | `e4s-local` | Bạn bè và người kiểm thử dùng. Chỉ cập nhật khi đưa bản mới lên. |
| Sửa code | http://127.0.0.1:4300 (API riêng ở 4301, Postgres ở 127.0.0.1:5434) | `e4s-dev` | Sửa và thử code. Có DB và kho ảnh/audio riêng, chép từ 4175. |

Hai bản không dùng chung dữ liệu. Thao tác trên 4300 (đăng nhập, đổi ngày thử, nộp bài, duyệt) không ảnh hưởng 4175. Bản 4300 không có đường hầm Cloudflare nên chỉ mở được trên máy này.

Chạy các lệnh dưới đây trong thư mục repo.

## Cập nhật 4300 sau khi sửa code

```bash
docker compose -p e4s-dev -f docker-compose.yml -f docker-compose.dev4300.yml build api web worker
docker compose -p e4s-dev -f docker-compose.yml -f docker-compose.dev4300.yml up -d --no-deps api web worker
```

## Đưa bản đã thử lên 4175

Commit trước, rồi build đúng các service ứng dụng. Không chạy service `migrate` và không chạy `up` thiếu `--no-deps`, vì `migrate` đặt lại mật khẩu nhân viên.

```bash
docker compose -p e4s-local -f docker-compose.yml -f docker-compose.tunnel.yml build api web worker
docker compose -p e4s-local -f docker-compose.yml -f docker-compose.tunnel.yml up -d --no-deps api web worker
```

Nếu có migration mới trong `packages/database/migrations`, áp lên 4300 trước. Khi đã ổn, áp lên 4175 bằng một script chỉ gọi `migrateDatabase`, không dùng service `migrate`.

## Chép lại dữ liệu mới nhất từ 4175 sang 4300

Lệnh này ghi đè toàn bộ DB của 4300.

```bash
docker compose -p e4s-local -f docker-compose.yml -f docker-compose.tunnel.yml exec -T postgres sh -c 'pg_dump -U "$POSTGRES_USER" -d "$POSTGRES_DB" -Fc' > 4175.dump
docker compose -p e4s-dev -f docker-compose.yml -f docker-compose.dev4300.yml exec -T postgres sh -c 'psql -U "$POSTGRES_USER" -d postgres -c "drop database if exists \"$POSTGRES_DB\" with (force)" -c "create database \"$POSTGRES_DB\""'
docker compose -p e4s-dev -f docker-compose.yml -f docker-compose.dev4300.yml exec -T postgres sh -c 'pg_restore -U "$POSTGRES_USER" -d "$POSTGRES_DB" --no-owner' < 4175.dump
docker compose -p e4s-dev -f docker-compose.yml -f docker-compose.dev4300.yml restart api worker
```

Ảnh và audio nằm trong MinIO. Muốn chép cả phần này, dừng MinIO của 4300, chép volume `e4s-local_e4s-minio` sang `e4s-dev_e4s-minio`, rồi bật lại.
