# E4S bundled artwork

All raster artwork in this directory comes from official [Kenney](https://kenney.nl/) asset packs and is released under [Creative Commons Zero 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (`CC0-1.0`). Attribution is not required by the licence; this file records provenance so every copied asset remains auditable.

The committed `manifest.json` pins the exact SHA-256 digest for every file.
